# features/

Discussion stage for a **new rule feature** (an addition to the game's rules, not a change to
existing behaviour) — see [`../CLAUDE.md`](../CLAUDE.md), "What still holds from the old model".

One directory per feature: `features/<slug>/` holding `user_story.md`, `planning.md`, and a
`diagram/` folder. Formalise into `docs/todo/` + `TODO.md` and `docs/instruction/` +
`instruction.md` before implementation.
